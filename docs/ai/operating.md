# KATACHI の記入例（体制の型 `framework/README.md` をこの事業で使う）

- 目標の鎖：提携する工場・設計の相談先 → 独自の中身（作例・品目ごとの必要情報・会社のプロフィール） → 被リンク → 集客 → 見積の依頼・相談 → 売上
- ペルソナ：①ただの個人・素人（自分の商品を作りたい。図面がない）②中小企業・お店（自社製品・小口の試作）③工場・開発企業（空き枠を埋めたい・小口でも受けたい）
- 4つの目（鏡）：依頼する人（個人・会社）／お金／集客（SEO）／工場・設計の相談先
- マッチングの精度がいちばん大事（Nori 2026-11-15「マッチング精度が命」）：会社の並びを変えたら `match_eval.js --check` を通してから（`AGENTS.md`）。
- 送る係：工場へのメールは受付（`backend/forms.gs`）の差出人だけ。AI は下書きまで。
- 担当のスレッド：要・策・問・灯・結・算・種・縁・道・形・文・鏡・関 をどのスレッドが持つかは、プロジェクトを作ったときにここへ書く。
- お金の決まり：Nori さんが決めた条件だけ。率は公開のリポジトリに書かない。
