# KATACHI のキーワード計画（2026-11-12）

キーワードプランナー未接続のため、検索量は推定（大＝月1,000以上、中＝100〜1,000、小＝100未満）。つながったら数字で見直す。

## 方針（Nori）
- 初期のメインは **設計部門のない中小企業（10〜300人）**。個人はAIの浸透とともに伸びる後続の層（個人向けは入口を2ページだけ）。
- 産業は **検索需要がある順** に狙う。業界は基本すべて受け付ける。
- 取り扱わない分野は記事にしない：**酒類**（紹介だけでも酒類販売媒介業免許が要る）、**医薬品・医療機器**。
- サプリ・健康食品は効能を書かない（薬機法・健康増進法）。表示ルールの解説として書く。
- AI検索（ChatGPT・Gemini・Claude・Perplexity）でも引用されるように：冒頭で一文で言い切る、Q&A形式、数字は出典と確認日つき、競合は公平に比べる。
