DMM.make 3Dプリントの使い方：法人・個人の注文の流れ、データの決まり、向いている使い方

更新日：2026/11/13

DMM.make 3Dプリントは、3Dデータをアップロードすると見積が出て、選んだ素材で3Dプリントした物が届く出力サービスです。法人も個人も使え、3Dデータの作成や修正を頼むオプションもあります。この記事では、公式サイトに書かれていることをもとに、注文の流れ、素材と料金の決まり方、データの作り方の決まり、ほかのサービスとの使い分けをまとめます。

この記事の要点
  • モデルデータを上げると、データのチェック結果と見積が表示される（Webで約1分）
  • 法人は、簡易見積→法人登録と3Dプリント利用登録→正式な見積書→製作・配送の流れ。最短翌日に製作して配送と書かれている
  • 選べる素材は46種。料金の目安は素材ごとの「1cm³あたりの材料費」で示され、サイズや形で変わる
  • データはmm単位・実物の大きさでつくり、1ファイル100MB・100シェルまで。面に穴やねじれのない一体のモデルにする
  • 3Dデータがなければ、3Dデータの作成・修正のオプションや、設計から頼める先を使う

DMM.make 3Dプリントとはどんなサービス？

DMM.make 3Dプリントは、3Dプリンターでの出力の代行から、つくった物の販売までを扱うサービスです。公式サイトでは、ビジネス・個人・クリエイター向けとされ、造形した物は国内外のプリントセンターから「日本全国送料無料でお届け」と書かれています（2026年11月13日確認）。

  • 選べる素材：46種（樹脂・金属など）
  • 見積：モデルデータを上げると、データのチェック結果と見積が表示される。Webで約1分、そのまま注文もできる
  • 納期：「最短翌日」に製作して配送（受注の状況で変わる）。2026年のお知らせでは、受注が多いことによる納期の遅れが案内されていた
  • オプション：3Dデータの作成・修正（作成代行）、3Dスキャン、即納サービス
  • 支払い：クレジットカード払いか請求書払い（手数料500円）

3Dプリントの方式や素材の選び方そのものは3Dプリンターの依頼・外注ガイドで詳しく説明しています。

DMM.make 3Dプリントの使い方：法人の注文の流れ

法人向けのページでは、次の4つの流れが示されています。

  1. 無料で簡易見積：モデルデータをアップロードすると、モデルのチェック結果と見積が表示される
  2. 法人登録と3Dプリント利用登録：メールフォームから問い合わせて登録する
  3. 正式な見積の確認：モデルのチェックをもう一度行い、正式な見積書がメールで届く
  4. 配送・納品：最短翌日に製作して配送する

会社で使う場合は、正式な見積書をもらってから社内の決裁を通す、という順番にしやすい流れです。請求書での支払いも選べます。

DMM.make 3Dプリントの使い方：個人の注文の流れ

個人向けのページでは、次の4ステップで説明されています。

  1. 3Dデータを準備する
  2. 3Dデータをアップロードして、即時見積を見る（概算の料金がすぐ表示される）
  3. 素材を選ぶ（注文の前にサンプルで質感や強度を確かめることもできる）
  4. 注文・決済（クレジットカードなど。DMMポイントも使える）

個人のページでは、つくった物をマーケットで販売するしくみも紹介されています。出品の費用は0円で、在庫を持たずに売れ、注文が入るとDMM.makeが造形して購入者に届ける、と書かれています。個人で物をつくって売る全体の流れは個人で商品を作りたいときにまとめています。

DMM.make 3Dプリントの料金とデータの決まり

料金の決まり方

公式サイトでは、素材ごとに「1cm³あたりの材料費の目安」が示されています（例：PA12（MJF）は113円〜、64チタン（SLM）は2,178円〜）。ただし「サイズや形状に応じて変動いたします」とあり、実際の金額はデータを上げたときの見積で決まります。同じ形でも、素材を変えると金額が大きく変わるので、見積の画面で素材を切り替えて比べるとよいでしょう。

3Dデータの作成ルール

項目決まり
形式（色なし）STL、3MF、OBJ、3DS、STEP、PLY、VRML
形式（フルカラー）3MF、OBJ、PLY、VRML。色やテクスチャの情報を1つにまとめてZIPで圧縮
単位と大きさmm。3Dプリントしたい実物の大きさでつくる
ファイルの大きさ1ファイル100MBまで（ZIPで圧縮しても同じ）
シェルの数1ファイル100シェルまで
モデルの形面がすべてつながった一体のモデル（ソリッド）で、面に穴があいていない・ねじれていないこと

出典：DMM.make 3Dプリント「3Dデータの作成ルール」（2026年11月13日確認）。

最小の厚みや造形できる大きさは、素材ごとの「デザインガイドライン」に書かれていると案内されています。素材を決めたら、そのガイドラインで確かめてから注文します。

DMM.makeで注文する前に確かめること

  • 素材のガイドライン：最小の厚みや造形できる大きさは素材ごとに違います。素材を決めたら、その素材のデザインガイドラインを読みます。
  • 見積の画面で素材を比べる：同じ形でも素材で金額と仕上がりが変わります。強さが要るのか、見た目を確かめたいのかで選びます。
  • 納期の余裕：最短翌日と書かれていますが、受注の状況で変わり、2026年には納期の遅れのお知らせも出ていました。日程に余裕をみて注文します。
  • 支払い方法：クレジットカードか請求書払い（手数料500円）かを決めておきます。
  • 何を確かめる試作か：形・大きさ・組み合わせ・強さのどれを確かめたいかで、素材と数が決まります。

はじめての素材は、注文の前にサンプルで質感を確かめられると個人向けのページに書かれています。

DMM.makeと他のサービスの使い分け：データがない場合は？

手元にあるもの・目的向いている頼み方
3Dデータがあり、樹脂や金属の3Dプリントで形にしたいDMM.makeなどの出力サービス
3Dデータはないが、形はスケッチや現物で決まっているDMM.makeの3Dデータ作成・修正のオプション、データ作成を受ける会社
切削や板金の金属部品として形にしたい3D CADから即時見積が出る部品のサービス（meviyの使い方）、加工の会社
電子回路や縫製なども入った製品を、まとめて試作したい設計から引き受ける試作会社。工程に分けて頼み先を探すサービス

DMM.makeは、形を1個から早く確かめるのに向いた入口です。製品の一部（外装など）は3Dプリントで、電子回路は基板の会社で、のように工程ごとに頼み先を分けると、製品全体の試作が進めやすくなります。KATACHIは、つくりたいものを文章で書くと工程に分けて頼み先を探せるので、DMM.makeで外装を試作しつつ、ほかの工程の会社を探す、という使い方ができます。

よくある質問

DMM.make 3Dプリントは個人でも使えますか？
使えます。公式サイトには個人向けのページがあり、3Dデータを上げて即時見積を見て、素材を選び、クレジットカードなどで注文する流れが示されています。
DMM.makeで使えるデータ形式は？
色なしの造形ではSTL・3MF・OBJ・3DS・STEP・PLY・VRMLに対応しています。単位はmmで、1ファイル100MB・100シェルまでです。
3Dデータがなくても頼めますか？
3Dデータの作成・修正を頼めるオプションが案内されています。電子回路などを含む製品全体の試作なら、設計から引き受ける試作会社に相談する方法もあります。
料金はどうやって決まりますか？
素材ごとに1cm³あたりの材料費の目安が示されていますが、サイズや形で変わります。データをアップロードしたときの見積で確かめてください。
つくりたいものを書くだけで、工程ごとに頼める会社をさがせます

KATACHIでは、AIが作り方を工程に分け、図面なし・試作・小ロットで相談できる会社を組み合わせて提案します。工程の整理・会社の検索・見積の依頼は無料です。
