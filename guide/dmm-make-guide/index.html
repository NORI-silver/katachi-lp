DMM.make 3Dプリントの使い方：法人・個人の注文の流れ、データの決まり、向いている使い方

更新日：2026/11/13

DMM.make 3Dプリントは、3Dデータを上げると見積が出て、選んだ素材で造形した物が届く出力サービスです。法人も個人も使え、3Dデータの作成・修正も頼めます（公式サイトの記載より）。

この記事の要点
  • モデルデータを上げると、データのチェック結果と見積が出る（Webで約1分）
  • 法人は簡易見積→法人登録・利用登録→正式見積書→製作・配送。最短翌日に製作して配送と記載
  • 素材は46種。料金は素材ごとの「1cm³あたりの材料費」が目安で、サイズや形で変わる
  • データはmm単位・実物大、1ファイル100MB・100シェルまで、穴やねじれのない一体のモデル
  • 3Dデータがなければ作成・修正のオプションか、設計から頼める先を使う

01DMM.make 3Dプリントとはどんなサービス？

3Dプリントの出力代行から、つくった物の販売までを扱うサービスです。ビジネス・個人・クリエイター向けで、国内外のプリントセンターから「日本全国送料無料でお届け」とあります（2026年11月13日確認）。

  • 素材：46種（樹脂・金属など）
  • 見積：データを上げるとチェック結果と見積。Webで約1分、そのまま注文可
  • 納期：「最短翌日」に製作・配送（受注状況で変わり、2026年は遅れの案内あり）
  • オプション：3Dデータの作成・修正、3Dスキャン、即納
  • 支払い：クレジットカードか請求書（手数料500円）

方式や素材の選び方は3Dプリンターの依頼・外注ガイドへ。

02DMM.make 3Dプリントの使い方：法人の注文の流れ

1無料で簡易見積→2法人登録と利用登録→3正式な見積→4配送・納品
  1. 無料で簡易見積：データを上げるとチェック結果と見積が出る
  2. 法人登録と利用登録：メールフォームから登録
  3. 正式な見積：再チェックのうえ見積書がメールで届く
  4. 配送・納品：最短翌日に製作・配送

正式な見積書で社内決裁を通しやすく、請求書払いも選べます。

03DMM.make 3Dプリントの使い方：個人の注文の流れ

  1. 3Dデータを準備する
  2. アップロードして即時見積を見る
  3. 素材を選ぶ（サンプルで質感・強度を確かめられる）
  4. 注文・決済（クレジットカードなど、DMMポイントも可）

つくった物をマーケットで売るしくみもあり、出品0円・在庫なしで、注文が入るとDMM.makeが造形して届けます。全体の流れは個人で商品を作りたいときへ。

04DMM.make 3Dプリントの料金とデータの決まり

料金の決まり方

素材ごとに「1cm³あたりの材料費の目安」があります（例：PA12（MJF）113円〜、64チタン（SLM）2,178円〜）。「サイズや形状に応じて変動」するので、見積画面で素材を切り替えて比べます。

3Dデータの作成ルール

項目決まり
形式（色なし）STL、3MF、OBJ、3DS、STEP、PLY、VRML
形式（フルカラー）3MF、OBJ、PLY、VRML。色・テクスチャをまとめてZIP
単位と大きさmm、実物の大きさ
ファイルの大きさ1ファイル100MBまで（ZIPでも同じ）
シェルの数1ファイル100シェルまで
モデルの形面がつながった一体のモデル（ソリッド）、穴・ねじれなし

出典：DMM.make 3Dプリント「3Dデータの作成ルール」（2026年11月13日確認）。

最小の厚みと造形サイズは素材ごとの「デザインガイドライン」で確かめます。

05DMM.makeで注文する前に確かめること

  • 素材のガイドライン最小の厚み・造形サイズは素材ごとに違う。
  • 見積画面で素材を比べる強さが要るか、見た目の確認かで選ぶ。
  • 納期の余裕最短翌日でも受注状況で変わる（2026年に遅れの案内あり）。
  • 支払い方法カードか請求書（手数料500円）。
  • 何を確かめる試作か形・大きさ・組み合わせ・強さで素材と数が決まる。

06DMM.makeと他のサービスの使い分け：データがない場合は？

手元にあるもの・目的向いている頼み方
3Dデータがあり、3Dプリントで形にしたいDMM.makeなどの出力サービス
データはないが、形はスケッチや現物で決まっているDMM.makeの3Dデータ作成・修正、データ作成を受ける会社
切削や板金の金属部品にしたい3D CADの即時見積サービス（meviyの使い方）、加工の会社
回路や縫製も入った製品をまとめて試作したい設計から受ける試作会社、工程に分けて頼み先を探すサービス

DMM.makeは形を1個から早く確かめる入口です。外装は3Dプリント、回路は基板の会社のように分けると製品全体が進めやすく、KATACHIなら外装以外の工程の会社も文章から探せます。

Q&Aよくある質問

QDMM.make 3Dプリントは個人でも使えますか？
A使えます。個人向けページでは、3Dデータを上げて即時見積を見て、素材を選び、カードなどで注文する流れです。
QDMM.makeで使えるデータ形式は？
A色なしはSTL・3MF・OBJ・3DS・STEP・PLY・VRML。mm単位で、1ファイル100MB・100シェルまでです。
Q3Dデータがなくても頼めますか？
A3Dデータの作成・修正のオプションがあります。回路なども入る製品全体なら、設計から受ける試作会社に相談します。
Q料金はどうやって決まりますか？
A素材ごとに1cm³あたりの材料費の目安がありますが、サイズや形で変わります。データを上げたときの見積で確かめてください。
つくりたいものを書くだけで、工程ごとに頼める会社をさがせます
