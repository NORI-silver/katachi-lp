3Dプリント出力サービスの価格はどう決まる？素材別の目安と、費用を下げるコツ

更新日：2026/11/14

3Dプリントの出力サービスは個人でも1個から使え、価格は「体積×素材の単価」に方式・大きさ・後処理・オプションの費用が加わって決まります。素材だけで材料費の目安は10倍以上違い、空洞化・まとめて出す・仕上げを減らすと下がります。

この記事の要点
  • 中心は材料費（体積×素材の単価）。造形の手間、サポート除去・塗装などの後処理、短納期などのオプションが加わる
  • 素材の差が大きい。DMM.make の目安は1cm³あたりPP（SLS）63円〜、PA12（MJF）113円〜、標準レジン180円〜、ゴムのような樹脂807円〜
  • 体積を減らす（空洞・肉抜き）、安い素材、オプションを絞ると下がる
  • 公設試で機械を借りる例：光造形1時間4,100円（宮城県）〜6,430円（山梨県）。材料・人の作業は別
  • 数が多いと射出成形のほうが安いことがある。数量ごとに比べる

013Dプリント出力サービスの価格の決まり方

見積はおおむね次の積み上げです。何で上下するかを知れば、データの段階で費用を下げられます。

要素中身価格が上がりやすいとき
材料費体積（方式によりサポート材も）×素材の単価中身が詰まった大きな部品、単価の高い素材
造形の手間機械の稼働時間、造形の準備背が高い（層が多い）、機械を長く使う
後処理サポート除去、洗浄、研磨、塗装、染色サポートが多い形、見た目の仕上げ
オプション3Dデータの作成・修正、短納期、検査データがない、急ぐ
数量同じ部品の個数（数で単価が下がることもあるが、型を使う加工ほどは下がらない）

出典：DMM.make「3Dプリントで安く造形したい！相場やコスト削減のコツ」（2024年1月12日）。素材・サイズや体積・造形方式・オプションを価格の要素に挙げている。

02試作品は1個から作れる？本番の最小ロットとの違い

試作（サンプル）と本番の最小ロットは別です。試作は本番の前に形や中身を確かめる見本で、1個〜少しだけつくり、費用は本番とは別に見積もられます（無料のサンプルを出す会社もあります）。最小ロットは、本番で一度に頼む数の下限です。

試作（サンプル）本番（量産）
何個1個から。3Dプリントや切削は型が要らない3Dプリント・切削・板金は本番も1個から頼める（最小ロットのない頼み先が多い）。数が多いと型を使う成形が安くなる
費用切削1個3,900〜52,220円（meviy）、ナイロンの3Dプリント手のひら大1個3,000〜4,000円の報道例（MONOist）初期費用（型・版など）＋単価×数量
型要らない（3Dプリント・切削・板金）射出成形は金型が要る。試作・少量向けで30万〜40万円、国内の量産金型で300万円の報道例（MONOist、2015年）

流れは「試作で確かめる → 直す → 本番を最小ロット以上で頼む」。見積は試作と本番を分けて出してもらいます。

03個人で3Dプリントを頼むとき、費用で気をつけること

  • 個人で受けてもらえるか最初に聞く法人のみの会社もある。「個人であること・最初の数・予算・売り方」を1通目に書く。
  • 最低料金と送料小さな物1個だと割高。まとめて頼める物はまとめる。
  • データ作成は別料金データがないときは作成費が加わる。
  • 売るなら個人でも事業者ネット販売は特定商取引法の表示（氏名・住所・電話番号など）が要る。開業届など全体の手順は個人でも自分の商品は作れるへ。

04法人・お店として頼むとき

  • 最初の1通に会社の情報を書く会社名・用途（販売／配布／店舗で使う）・数・希望の時期・予算。法人だけ受ける会社にも頼める。
  • 図面がなくても会社として頼める用途・大きさ・数・予算の4点で相談できる。進め方は試作の外注の進め方と図面がなくても加工は頼める？へ。
  • 見積は同じ条件で並べる数・仕様・納期をそろえて複数社に聞くと、差が単価なのか仕様なのかがわかる。
  • 工程が分かれるなら取りまとめ役を1社決める中身・容器・印刷・箱などを別の会社に頼むときは、窓口と責任の範囲を最初に書面で決める。
  • 社内に設計担当がいなくても進められる委託先の探し方は製造の委託先の探し方、全体の進め方は自社製品の開発の進め方、費用の一部はものづくり補助金が使える場合がある。

06大きさ・形で3Dプリントの価格が変わる理由

  • 体積材料費の中心。外形が同じでも中身が詰まると高い。
  • 高さ1層ずつ積むので背が高いほど時間がかかる。向きで変わることもある。
  • 張り出し（オーバーハング）光造形・FDMはサポートが要り、材料と除去の手間が増える。粉末の方式（SLS・MJF）は一般に不要。
  • 細かさ薄い壁・小さな文字・細いピンは方式によりつくれないか、きれいに出ない。
  • 最大サイズ超え分けて造形して貼り合わせるか、問い合わせ。

083Dプリントの費用を下げるコツ

1空洞にする・肉を抜く→2目的に合った安い素材→3部品をまとめて出す→4オプションを絞る→5精度の指示を絞る→6数が増えたら工法を比べる
  1. 空洞にする・肉を抜く：体積が減れば材料費が下がる。粉末の方式は粉を抜く穴が要ることも。
  2. 目的に合った安い素材：形の確認に高精細・特殊な素材は要らないことが多い。
  3. 部品をまとめて出す：1つのデータにまとめて並べると安くなる例がある（DMM.make。条件はサービスの決まりを確認）。
  4. オプションを絞る：塗装・研磨・短納期は要る試作だけ。
  5. 精度の指示を絞る：はめ合いなど大事な所だけ指示し、他は標準。
  6. 数が増えたら工法を比べる：射出成形や真空注型が1個あたり安くなることも（射出成形を小ロットで頼む）。

093Dプリントの見積を比べるときの見方

  • 同じデータ・素材・仕上げで取る。素材名が違えば性質（強さ・耐熱・透明さ）をそろえる。
  • 含まれるものサポート除去、表面仕上げ、送料、消費税。
  • 納期標準納期と短納期の追加料金。
  • データの修正問題があったとき直してくれるか、費用は。
  • 数量ごとの単価1個と10個でどう変わるか。

3Dデータがなければ作成費が加わります（図面がなくても加工は頼める？）。試作全体は試作の外注の進め方へ。

Q&Aよくある質問

Q試作品は1個から作ってもらえますか？最小ロットとは別ですか？
A3Dプリントや切削なら試作も本番も1個から頼めます。型を使う射出成形に移ると、金型代（試作・少量向けで30万〜40万円の報道例）がかかり、最小ロットも出てきます。
Q会社やお店として頼むときは何が違いますか？
A会社名・用途・数・予算を最初に伝えると、法人だけ受ける会社にも頼めます。販売者・発売元などの表示は自社名にでき、工程が分かれるときは取りまとめ役を1社決めます。
Q個人でも3Dプリントの出力サービスを使えますか？
A使えます。個人の注文を受けるサービスでは、データを上げると即時見積が出て1個から注文できます。
Q3Dプリントの価格は何で決まりますか？
Aおもに材料費（体積×素材の単価）に、造形時間・後処理・データ作成や短納期などのオプションが加わります。素材と方式の差が大きいので、目的に合った素材を選ぶことが大切です。
Q小さな部品なら安くなりますか？
A材料費は下がりますが、最低料金や送料で1個あたりは割高になることがあります。複数の部品をまとめて頼めるか確かめましょう。
Q自分で3Dプリンターを買ったほうが安いですか？
Aたまにしか使わないなら外注、頻繁に使うなら自社で持つ選択肢があります。公的機関で借りたり外注で試したりしてから判断する方法もあります。
Q見積の金額が会社ごとに違うのはなぜですか？
A機械・素材・仕上げの範囲・送料や最低料金の決め方が違うためです。同じデータ・素材・仕上げで取り、含まれるものをそろえて比べてください。
