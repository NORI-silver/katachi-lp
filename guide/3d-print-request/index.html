3Dプリンターの依頼・外注ガイド：頼み先と方式の選び方、データがないときの頼み方

更新日：2026/11/12

3Dプリントは3Dデータを送れば1個から形にしてもらえる試作の入口です。頼み先は即時見積の出力サービスから、データ作りから受ける試作会社まで。法人・個人のどちらにも使えます。

この記事の要点
  • 3Dデータ（STL・STEPなど）があれば、出力サービスで1個から頼める
  • データがなければ、データ作成の請負か試作会社へ
  • 形の確認＝FDM、強さ・動き＝ナイロン系、見た目・透明＝光造形、金属＝金属方式
  • 費用は大きさ・方式・素材・仕上げ・数量で決まる。同じデータで複数社を比べる
  • 使い道は試作が約3分の2（世界調査67%）。本番部品21%で、輸送機器・ロボットで多い
  • 数が増えると型を使う成形が安い。試作時に量産方法も相談

013Dプリンターの依頼先4つ：どこに頼むか

頼み先3Dデータ向いている場面
オンラインの3Dプリント出力サービス必要データがあり、早く・手軽に1個から欲しいとき。即時見積が多い。個人も可が多い
試作会社・設計会社なくても相談可データ作りから、仕上げ・組み立て・評価まで任せたいとき
3Dデータ作成の請負（会社・個人）つくってもらうスケッチや写真しかなく、まずデータが欲しいとき
地域の工房・公的な機関必要なことが多い機械を借りて自分で出力したいとき、相談しながら進めたいとき

使い道は試作が中心で、本番部品や治具に広がりつつある段階です（社内出力と外注の合計）。

使い道：試作が約3分の2、本番部品が約2割

業種別：どの業種が何に使っているか

業種調査でわかっていること（Protolabs 2024）よくある使い道の例
輸送機器・自動車本番の部品に使う割合が33%（全体平均21%）。自動車ではナイロン粉末の方式（SLS）が20%内装・部品の試作、少量の補修部品、組み立ての治具
ロボット・産業オートメーション本番の部品に使う割合がロボット30%、産業オートメーション27%ロボットの手先・カバー、装置ごとの専用部品
電子機器前年より多く出力した割合が83%。粉末を固める方式（MJF）が15%ケース（筐体）の試作、少量品のケース
農業・建設前年より多く出力した割合が農業87%・建設79%。どちらも樹脂を積む方式（FDM）が中心機械の補修部品、現場で使う治具
デザイン見た目のための部品に使う割合が9%（全体平均4%）展示用のモデル、モックアップ

全業種の方式はFDM 59%、光造形（SLA）20%、SLS 11%、MJF 7%。右列は調査の数字ではなく一般的な例です。

設計部門のない中小企業の使い道

  • 新商品の形・大きさを確かめるモックアップ
  • 展示会・商談のサンプル
  • 店舗の什器・ディスプレイ部品、少量のグッズ
  • 型で量産する前の形の最終確認

データがないことが多いので、データ作りから受ける先が近道です。→ 試作・製造の依頼で実際に多いもの

03目的別：3Dプリントの方式と素材の選び方

目的向いている方式特徴
形や大きさの確認熱で溶かした樹脂を積む方式（FDM）比較的安く早い。表面に積層の筋が出やすい
見た目・細かい形・透明光で樹脂を固める方式（光造形・SLA）表面がなめらかで細かい形が得意。強さや耐熱は素材による
強さ・はめ合い・動く部品粉末のナイロンを固める方式（SLS・MJF）丈夫で、機能を試す試作や少量の本番部品にも使われる
金属部品金属の粉末を溶かして固める方式複雑な金属形状をつくれる。費用は樹脂より高い

迷ったら「何を確かめるか」「使う環境（屋外・熱・水）」を伝えれば提案してもらえます。

043Dデータがないときの頼み方

1データ作成を頼む→2試作会社にまとめて頼む→3現物をスキャンする→4自分でつくる
  1. データ作成を頼む：スケッチ・写真・寸法からCADデータに。できれば複数の出力サービスで比べられる。
  2. 試作会社にまとめて頼む：データ・出力・仕上げまで一括。
  3. 現物をスキャンする：精度が要る部品はスキャン後にCADで整える。
  4. 自分でつくる：無料の3D CADで単純な形なら最速。

053Dプリントの依頼で費用が決まる要素

  • 大きさ材料の量（体積）と造形時間（高さ）。
  • 方式と素材樹脂より金属、汎用より特殊樹脂が高い。
  • 仕上げサポート除去・研磨・塗装・染色。
  • 数量複数で1個あたりが下がることがある。
  • データ作成データがなければ別費用。

同じデータ・条件で2〜3社の見積と提案を比べます。

06試作から量産へ：3Dプリントのままでいいか

3Dプリントは数が増えても単価が下がりにくく、量が増えると射出成形など型を使う方法が安くなります。

  • 試作時に「量産なら何個か」を伝え、量産方法も相談する
  • 型に移ると、型から抜ける形への変更が要ることがある
  • 少量の本番品は、ナイロン系の3Dプリントのまま販売する例もある

電子回路や布にもまたがる製品は工程ごとに頼み先を分けます。→ 試作の外注の進め方

Q&Aよくある質問

Q3Dプリンターの依頼は個人でもできますか？
Aできます。出力サービスの多くは個人も受けています。データがなければ作成の請負に頼めます。
Q3Dデータはどんな形式で送ればいいですか？
ASTLが一般的で、STEP・OBJ・3MFも多く受け付けます。精度が大事な部品はSTEPなどCADの元データも送ると確実です。
Qフィギュアやキャラクターの造形も頼めますか？
A受ける先はありますが、他人の著作物（アニメや商品のキャラクターなど）は権利者の許可が必要です。自作・権利のあるものを依頼しましょう。
Q3Dプリントの試作品をそのまま販売できますか？
A少量なら丈夫な素材でそのまま販売する例もあります。数が多い・安全基準がある製品は、量産方法と検査を依頼先と相談してください。
