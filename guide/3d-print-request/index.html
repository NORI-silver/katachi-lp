3Dプリンターの依頼・外注ガイド：頼み先と方式の選び方、データがないときの頼み方

更新日：2026/11/12

3Dプリントは、3Dデータを送れば1個から形にしてもらえる、試作のいちばん身近な入口です。頼み先は、データを送ると即時に見積が出る出力サービスから、データ作りから引き受ける試作会社まであります。この記事では、法人・個人どちらにも使えるように、頼み先の選び方、目的に合った造形方式と素材、3Dデータがないときの頼み方、試作から量産へ移るときの考え方をまとめます。

この記事の要点
  • 3Dデータ（STL・STEPなど）があれば、オンラインの出力サービスで1個から頼める
  • データがなければ、3Dデータの作成から受ける会社や個人、または試作会社に頼む
  • 形の確認なら樹脂の安い方式、強さや動きを試すならナイロン系、見た目や透明さなら光造形、金属なら金属の方式を選ぶ
  • 費用は、大きさ（体積・高さ）・方式・素材・仕上げ・数量で決まる。同じデータで複数社の見積を比べる
  • 使い道は試作が約3分の2（世界の調査で67%）。本番部品は21%で、輸送機器・ロボット・産業オートメーションで多い
  • 数が増えると、型を使う成形などのほうが1個あたり安くなる。試作の段階で量産の方法も相談しておく

013Dプリンターの依頼先4つ：どこに頼むか

頼み先3Dデータ向いている場面
オンラインの3Dプリント出力サービス必要データがあり、早く・手軽に1個から欲しいとき。即時見積が多い
試作会社・設計会社なくても相談可データ作りから、仕上げ・組み立て・評価まで任せたいとき
3Dデータ作成の請負（会社・個人）つくってもらうスケッチや写真しかなく、まずデータが欲しいとき
地域の工房・公的な機関必要なことが多い機械を借りて自分で出力したいとき、相談しながら進めたいとき

法人の試作なら、データがあれば出力サービス、なければ試作会社が基本です。個人で1個だけ欲しい場合も、出力サービスは個人の注文を受けているところが多くあります。

02どんな企業が何に3Dプリントを頼んでいるか：調査データ

3Dプリントの使い道は、いまも試作が中心で、本番の部品や治具（作業を助ける道具）に広がってきている段階です。社内で出力する場合と外注する場合を合わせた、公開されている2つの調査をまとめます。

使い道：試作が約3分の2、本番部品が約2割

試作67%形・デザインの試作 45.0%／機能・原理の試作 15.9%
本番の部品（最終製品）21%割合の公表なし（「まだ限定的」）
治具・型など6%治具・補助工具 16.6%

Protolabsの調査では、10個以上を出力した人の割合が2020年の36%から2023年には76%に増えていて、1個の試作から少量の生産へ使い方が広がっています。国内の調査では、職場に3Dプリンタがあると答えた人が43.5%でした（前回は37.8%）。

業種別：どの業種が何に使っているか

業種調査でわかっていること（Protolabs 2024）よくある使い道の例
輸送機器・自動車本番の部品に使う割合が33%（全体平均21%）。自動車ではナイロン粉末の方式（SLS）が20%内装・部品の試作、少量の補修部品、組み立ての治具
ロボット・産業オートメーション本番の部品に使う割合がロボット30%、産業オートメーション27%ロボットの手先・カバー、装置ごとの専用部品
電子機器前年より多く出力した割合が83%。粉末を固める方式（MJF）が15%ケース（筐体）の試作、少量品のケース
農業・建設前年より多く出力した割合が農業87%・建設79%。どちらも樹脂を積む方式（FDM）が中心機械の補修部品、現場で使う治具
デザイン見た目のための部品に使う割合が9%（全体平均4%）展示用のモデル、モックアップ

全業種で多い方式は、樹脂を積む方式（FDM）59%、光造形（SLA）20%、SLS 11%、MJF 7%の順でした。右の列は調査の数字ではなく、一般的な使い道の例です。

設計部門のない中小企業の使い道

製造業以外の会社でも、自社製品や店舗で使うものの試作に3Dプリントが使われています。例えば次のような使い道です。

  • 新商品の形や大きさを、社内や取引先に見せて確かめるためのモックアップ
  • 展示会や商談に持っていくサンプル
  • 店舗の什器やディスプレイの部品、少量のオリジナルグッズ
  • 型をつくって量産する前の、形の最終確認

こうした会社は3Dデータを持っていないことが多いため、データ作りから受ける依頼先を選ぶのが近道です（次の「3Dデータがないときの頼み方」を参照）。ほかの加工も含めて、実際にどんなものが発注されているかは試作・製造の依頼で実際に多いものにまとめています。

03目的別：3Dプリントの方式と素材の選び方

3Dプリントには方式がいくつかあり、得意なことが違います。名前より「何を確かめたいか」から選ぶと迷いません。

目的向いている方式特徴
形や大きさの確認熱で溶かした樹脂を積む方式（FDM）比較的安く早い。表面に積層の筋が出やすい
見た目・細かい形・透明光で樹脂を固める方式（光造形・SLA）表面がなめらかで細かい形が得意。強さや耐熱は素材による
強さ・はめ合い・動く部品粉末のナイロンを固める方式（SLS・MJF）丈夫で、機能を試す試作や少量の本番部品にも使われる
金属部品金属の粉末を溶かして固める方式複雑な金属形状をつくれる。費用は樹脂より高い

迷ったら、依頼先に「何を確かめる試作か」「どこで使うか（屋外・熱・水）」を伝えれば、方式と素材を提案してもらえます。

043Dデータがないときの頼み方

出力サービスは、3Dデータ（STL・STEP・OBJ など）を前提にしています。データがないときは、次のどれかから始めます。

13Dデータの作成を頼む→2試作会社にまとめて頼む→3現物をスキャンする→4自分でつくる
  1. 3Dデータの作成を頼む：スケッチ・写真・寸法を渡して、CADでデータを作ってもらいます。データができれば、複数の出力サービスで見積を比べられます。
  2. 試作会社にまとめて頼む：データ作り・出力・仕上げまで一括で頼めます。
  3. 現物をスキャンする：手元に形のある物があれば、3Dスキャンでデータにする方法もあります。寸法の精度が必要な部品は、スキャン後にCADで整えてもらいます。
  4. 自分でつくる：無料で使える3D CADもあります。単純な形なら、自分でつくって出力サービスに送るのがいちばん早い方法です。

053Dプリントの依頼で費用が決まる要素

金額は依頼先と条件で大きく変わるため、ここでは目安の金額ではなく、何で決まるかを整理します。

  • 大きさ使う材料の量（体積）と、造形にかかる時間（高さなど）。
  • 方式と素材一般に、樹脂より金属、汎用の樹脂より特殊な樹脂のほうが高くなります。
  • 仕上げサポート材の除去、研磨、塗装、染色など。
  • 数量同じものを複数つくると、1個あたりが下がることがあります。
  • データ作成や設計データがない場合は、その作成費が別にかかります。

同じデータ・同じ条件で2〜3社に見積を取り、方式や素材の提案も含めて比べるのが確実です。

06試作から量産へ：3Dプリントのままでいいか

3Dプリントは1個からつくれる反面、数が増えても1個あたりの値段が下がりにくい性質があります。数が増えると、型をつくって樹脂を流し込む射出成形や、型を使う別の方法のほうが1個あたり安くなります。

  • 試作の段階で、「量産するなら何個くらいか」を依頼先に伝え、量産の方法も相談しておく
  • 型を使う方法に移ると、形を少し変える必要が出ることがある（型から抜ける形にするため）
  • 少量の本番品なら、ナイロン系などの3Dプリントのまま販売する例もある

製品が外装だけでなく電子回路や布などにまたがる場合は、工程ごとに頼み先を分けて考えると進めやすくなります。進め方は試作の外注の進め方を見てください。

Q&Aよくある質問

Q3Dプリンターの依頼は個人でもできますか？
Aできます。オンラインの出力サービスの多くは個人の注文も受けています。3Dデータがない場合は、データ作成を請け負う会社や個人に頼む方法があります。
Q3Dデータはどんな形式で送ればいいですか？
ASTLがもっとも一般的で、STEPやOBJ、3MFを受ける依頼先も多くあります。依頼先が受け付ける形式を確認してから送りましょう。寸法の精度が大事な部品は、CADの元データ（STEPなど）も一緒に送ると確実です。
Qフィギュアやキャラクターの造形も頼めますか？
A造形自体を受ける依頼先はあります。ただし、アニメや商品のキャラクターなど他人の著作物を形にする場合は、権利者の許可が必要です。自分で描いたもの・権利を持っているものを依頼しましょう。
Q3Dプリントの試作品をそのまま販売できますか？
A少量なら、丈夫な素材の3Dプリント品をそのまま販売する例もあります。数が増える場合や、強さ・見た目・安全性の基準がある製品は、量産の方法と必要な検査を依頼先と相談してください。
