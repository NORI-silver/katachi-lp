### 大型犬用 車椅子（後ろ足を支える2輪）設計メモ

### 1. 目的
後ろ足が弱ってきたセントバーナード（体重50kg）が、散歩で自分で歩けるようにする車椅子を1台作りたい。販売はしない。

### 2. 犬のサイズ
- 体重50kg、体高（肩まで）75cm、胴の長さ80cm
- 腰の位置：床から60cm

### 3. 構成
| 部位 | 内容 |
|---|---|
| フレーム | アルミパイプ。高さと幅を調整できる |
| 車輪 | 直径30cm前後のゴムタイヤ2つ |
| 腰の支え | 布のサドル（洗える）とベルト |

### 4. 求めること
- 歩くときの姿勢が自然になるよう、腰を水平に支える
- 体温がこもらないよう、サドルは通気のよい布
- 段差（5cm程度）を越えられる

### 5. 電子部品
- 電子部品：使わない（電池・センサーなし）

### 6. 時期・予算
- 半年以内、予算は相談
